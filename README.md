# blog-dpInFabric-employeeVacation

This repository contains an example data product implementation for Microsoft Fabric.
To see the example in action, follow these steps:

1) Create a new workspace
2) Set up Git Integration with this repository
3) Copy both files into the 'lh_internal' lakehouse and load them as tables
4) Run your data product either through the included pipeline or using the transformation notebook.

In case of any difficulty in step 2 because of missing permissions, you might want to fork the repository.
